We turn the rules and routines of a business into software that is complex on the inside and simple to
use day to day. Before drawing the first screen, we learn the tasks and the exceptions of the operation.

| | |
|---|---|
| **[Safra em Dia](https://rvmit.com.br/en/safraemdia.html)** | Our product for agriculture. It follows production from the field to the lot sold, with cost and margin in plain sight, and the farmer can run it over WhatsApp in natural language. |
| **[Obra em Dia](https://rvmit.com.br/en/obraemdia.html)** | Our product for construction. It organizes people, machinery and housing costs per work front, and nothing gets allocated unless it is cleared. |
| **[Custom software](https://rvmit.com.br/en/sistemas-sob-medida.html)** | Systems built around each company's process, connected to what it already uses. |
| **[AI agents with control](https://rvmit.com.br/en/agentes-e-controle.html)** | Agents that work inside the systems with authorized context, allowed tools, permissions and human review on sensitive actions. |

**Stack:** .NET 10 · Blazor · PostgreSQL · Docker · LLM tool use and MCP · Claude Code and Codex in the
delivery process.

Our repositories are private. Open-source work lives on [@Elfarrar](https://github.com/Elfarrar).
